## Introduction
Deep nonnegative matrix factorization (DNMF) and its sparse variants are popular and powerful tools widely used for dimensionality reduction and clustering. The $\ell_{0}$-norm is the most intuitive representation of sparsity. Nevertheless, since the $\ell_{0}$-norm is nonconvex and nonsmooth, most existing DNMF methods employ the relaxation scheme of the $\ell_{0}$-norm to promote the sparsity of the factor matrices without explicitly controlling their sparsity levels, thereby reducing the feature extraction ability. To this end, we propose a novel sparse and graph-regularized deep nonnegative matrix factorization with $\ell_{0}$-constraints ($\ell_{0}$-SGDNMF) method, our method directly imposes the $\ell_{0}$-norm constraints to explicitly control the sparsity of the factor matrices in DNMF, thereby improving the quality of the extracted features. Furthermore, $\ell_{0}$-SGDNMF employs graph regularization to preserve manifold geometry information of data, thus integrating manifold learning and the $\ell_{0}$-norm constraints into DNMF. However, due to the nonconvex and nonsmooth properties of the $\ell_{0}$-norm constraints and the nonconvexity of DNMF, optimizing $\ell_{0}$-SGDNMF is NP-hard. To address these challenges, we propose a Block Proximal Gradient Hard-thresholding (BPGH) algorithm to solve the $\ell_{0}$-SGDNMF. Our algorithm provides a practical and convergent scheme to directly solve the original $\ell_{0}$-SGDNMF instead of solving its relaxed version. Furthermore, we prove that the bounded sequence generated by our algorithm is globally convergent to a critical point and analyze the per-iteration complexity of our algorithm. Experimental results on six real-world benchmark datasets show that our method outperforms several state-of-the-art methods for clustering. 

This package contains code for the $\ell_0$-SGDNMF problem in the paper[<sup>1</sup>](#refer-id). 

## Matlab code
A toy example explains how to use the these function. For "L0SGDNMF", before running it, first add the toolbox 'tensortoolbox'[<sup>2</sup>](#refer-id) (www.tensortoolbox.org) to the running path of matlab, and then run the function '[main_Run_me.m](L0SGDNMF/main_Run_me.m)'. 


## Data
This code has built-in the FashionMNIST and Pixraw10P datasets mentioned in our paper[<sup>1</sup>](#refer-id), and the rest of the data can be downloaded from the mentioned public website.
